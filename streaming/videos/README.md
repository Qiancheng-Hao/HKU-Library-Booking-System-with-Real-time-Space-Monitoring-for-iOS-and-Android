# Demo Videos

The default streaming demo now reads the four fixture videos from TOS:

```text
https://fyp.tos-cn-hongkong.volces.com/stream1.mp4
https://fyp.tos-cn-hongkong.volces.com/stream2.mp4
https://fyp.tos-cn-hongkong.volces.com/stream3.mp4
https://fyp.tos-cn-hongkong.volces.com/stream4.mp4
```

This folder is only for optional local/offline copies with these names:

```text
stream1.mp4
stream2.mp4
stream3.mp4
stream4.mp4
```

Local `.mp4` files in this folder are ignored by Git so large videos do not
accidentally bloat the repository.
