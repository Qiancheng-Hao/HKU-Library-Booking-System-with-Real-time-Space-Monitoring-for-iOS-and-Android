# Demo Videos

Place local demo videos here with these names:

```text
stream1.mp4
stream2.mp4
stream3.mp4
stream4.mp4
```

The four files are used by the `streaming` Docker Compose profile and are
intended to be committed as small demo fixtures.

Keep clips short and privacy-safe. Other mp4 files remain ignored by default so
large local videos do not accidentally bloat the repository.
